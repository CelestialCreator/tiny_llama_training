# TinyLlama Training Projects

This repository contains two implementations of TinyLlama model fine-tuning:

1. [Basic Training](./Basic_training/README.md): A simple implementation focusing on conversation flow.
2. [Advanced Training](./Advance_training/README.md): A comprehensive implementation supporting both role-based queries and conversation flow.

## Projects Overview

### Basic Training
- Simple conversation flow training
- Straightforward implementation
- Basic logging and monitoring

### Advanced Training
- Dual-purpose training (role-based & conversation flow)
- Enhanced data processing
- Comprehensive testing
- M1 Mac optimizations
- Detailed logging and monitoring

## Getting Started

Choose the appropriate implementation based on your needs:

- For simple conversation flow training: Use [Basic Training](./Basic_training/)
- For role-based queries and advanced features: Use [Advanced Training](./Advance_training/)
